Data sources: PubMed via NCBI E-utilities and ClinicalTrials.gov API v2. The default search excludes standalone SIRT/sirtuin terms to reduce false positives. Results are loaded by source page to improve performance on mobile devices; category, microsphere type, and country filters trigger a fresh search; the app scans source pages to fill each page with matching records when possible. Classification, device tagging, country inference, and summaries are rule-based and should be manually verified before external or promotional use. For PubMed, country is inferred from the author affiliation address tail when available; for ClinicalTrials.gov, country uses trial location data. The Multinational tag is inferred from multiple affiliation/location countries or explicit multicenter/international wording. Manual confirmation is still recommended for multi-center or multi-affiliation publications.
